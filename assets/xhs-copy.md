## 主推文案（技术向）

标题：开发者必备！把视频变成大模型能看懂的图片

正文：

做AI开发最头疼的是什么？
大模型看不了视频啊！！！

今天给大家安利一个自己做的开源工具
👉 FrameFlow — 视频关键帧提取神器

【它能干什么？】
把一段视频自动切成关键图片
提取最有代表性的画面，去掉重复的
直接喂给大模型理解视频内容

【三大核心功能】
1. 智能抽帧 — 场景检测 + 固定间隔双模式
2. pHash去重 — 感知哈希算法，自动去除重复画面
3. 大模型友好 — 自带提示词模板，一键复制直接用

【处理流程超清晰】
视频 → 智能抽帧 → 去重 → 均匀采样 → 输出图片+清单+网格图

【技术栈】
Python + Flask + ffmpeg + pHash
本地跑、Docker部署、Render上线都支持

开源地址：github.com/goodmore/FrameFlow

完全开源免费，star一下不迷路
